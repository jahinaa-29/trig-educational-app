## Description

Angle Explorer is a gamified educational app built in MATLAB App Designer that teaches 
middle schoolers triangle concepts — the Pythagorean Theorem and basic trig (sin, cos, 
tan) — through interactive visualizations, a lives system, and a friendly triangle mascot.

Inspired by Duolingo and Khan Academy, the goal was to make math feel less like homework 
and more like a game.

---

## Features

- **Live Triangle Visualization** — Sliders and input fields dynamically update the 
  triangle in real time. Adjust a side length and watch the angles recalculate instantly, 
  and vice versa
- **Lives System** — Wrong answers cost a life, adding game-like stakes that encourage 
  learning without discouraging students
- **Hints & Cheat Sheet** — On-demand hints, a quick-reference cheat sheet, and 
  solution reveals to support different learning speeds
- **Lesson + Practice Modes** — Structured lesson pages for each concept, plus a 
  dedicated practice mode with randomized problems
- **Angle Explorer Mascot** — An original animated triangular character that guides 
  students through the experience
- **Error Handling** — Catches empty or invalid inputs gracefully so the app never 
  breaks mid-session

## How to Run

**Requirements:** MATLAB (R2022a or later recommended) with App Designer

1. Clone or download this repository
2. Open MATLAB and navigate to the project folder
3. Open `home_page.mlapp` in App Designer  
   *(each page has its own `.mlapp` file — start from the home page)*
4. Click **Run ▶** in App Designer
