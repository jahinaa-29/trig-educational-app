# Angle Explorer - Interactive MATLAB Triangle Learning App for Middle School Students

This project is an educational app built in MATLAB App Designer designed to help middle school students learn triangle concepts, including the Pythagorean theorem and basic trigonometry (sine, cosine, tangent). 

Angle Explorer gamifies learning with interactive practice, hints, animations, and colorful multi-page navigation, making math engaging and approachable.

## 1. Home Page/Menu

The home page is a simple and easy-to-navigate UI design. As the primary audiences are middle schoolers, the whole experience is made to be engaging and vibrant. User has the option of picking either of the two concepts to learn via the Lesson Mode.
